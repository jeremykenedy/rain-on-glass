# Rain on Glass 1.1.0

Rain on Glass replaces the flat Canvas scene with GPU refraction, highlights and moving runoff over original bundled night and overcast city backgrounds. All six existing settings, the application ID and production signing key are preserved.

## Upgrade guide

Update version 1.0.0 in place with the signed `rain-on-glass.apk`:

```bash
python3 install.py --serial TV_IP:5555
```

The installer downloads the latest stable APK and checksum, verifies SHA-256 and asks before installation. For a downloaded local APK, use `python3 install.py --serial TV_IP:5555 --apk rain-on-glass.apk`. Keep the existing installation; removing it deletes saved preferences.

Android 6.0/API 23 or newer, DreamService support and OpenGL ES 2.0 are required. The package remains `com.jeremykenedy.rainonglass`; version 1.1.0 uses version code 2. No account, network permission, configuration migration, extra dependency or background service setup is required. Open settings, verify the saved choices, try Preview, then choose Rain on Glass in the TV's screensaver settings if wanted. Installation does not change the selected screensaver or system timers.

Back up your settings before rollback. Android normally rejects a lower version code; uninstalling to downgrade loses local preferences. There is no database migration.

## Breaking changes

No package, signing-key, settings-key or default change. The rendered appearance changes substantially. The renderer now requires OpenGL ES 2.0; devices without it cannot use this version. Android 6/API 23 remains the minimum.

## Major changes

- Refractive animated rain beads and narrow runoff trails replace the flat Canvas presentation.
- Original bundled night and overcast city backgrounds provide soft depth and distant light without runtime downloads.
- Existing density, speed, glow, focus and randomization options remain available through remote settings and the host content provider.

## Minor changes and fixes

- Add offline NOTICE and complete Apache license text through a remote-accessible Credits and licenses dialog.
- Enforce true 100 percent line and branch coverage for owned option validation and installer logic, and format the actual Java source tree.
- Refresh native scene, settings and credits documentation with the final signed build.

## Verification and limits

All host tests, installer tests, actual Java formatting, 100 percent owned line/branch coverage, documentation links, privacy checks and signed builds passed. Native API 34 D-pad checks scrolled the complete bundled license, selected Close, returned Preview to Settings and entered/exited the DreamService.

A physical Fire TV AFTDEC012E/API 30 retained all six exposed pre-update preferences during the same-signer update. After 40 seconds of the night/downpour/fast/crisp/glow preset, the production SurfaceView presented 30.24 frames per second over 126 presents. Menu leaves Preview active; Back returns Settings and Home exits. The overcast/few/slow/soft/no-glow preset also ran as the actual selected non-test DreamService and exited with Back. Normal-speed moving review confirmed coherent refraction and runoff without incidental text or watermarks. Original app preferences, selected screensaver, protected system settings and foreground protection were restored.

The exact tested APK is 1,942,951 bytes with SHA-256 `ca700f7717ed7d5e5aae1aa26da0615805a55cd8e0e8c066db81e69941aaf730`. Its production signer is unchanged. The short presentation sample is not encoded recording FPS or thermal endurance proof. Background plates are 1672x941; 1920x1080 native captures do not establish a native 4K buffer. Automatic idle entry, reboot and other physical Android TV/Google TV models remain untested.
