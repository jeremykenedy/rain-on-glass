# 1.1.0 candidate

Rain on Glass replaces the flat Canvas scene with OpenGL ES 2.0 refraction and highlights over original night and overcast city environments. The existing six settings, package identity and signing key are preserved.

The renderer uploads one batched droplet mesh, animates individual runoff on the GPU, and pauses with the native preview or dream. Source dimensions, background hashes and runtime assets are included in the APK.

The coverage build now enforces a true 100 percent line and branch ratio and formats the actual project source tree.

Native Google TV API 34 preview, actual DreamService binding/Back exit and density persistence were checked. Physical device and sustained worst-density performance gates remain pending. This candidate is not yet released.
