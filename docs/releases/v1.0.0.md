# Rain on Glass 1.0.0

First stable release of the animated rain-on-glass screensaver for Fire TV, Android TV, and Google TV.

## Included

- Continuously moving rain beads and runoff trails with an original procedural window scene.
- Night and overcast lighting, five rain density choices, three motion speeds, distant light, and soft or crisp glass focus.
- Per-setting random selection and a master randomize-on-start option.
- Remote-friendly settings and preview, plus a documented settings provider for host applications.
- Guided CLI install, SHA-256-verified release update, local APK install, and confirmed uninstall.
- No ads, analytics, tracking, reporting, app network permission, or runtime network requests.

## Compatibility

Android 6.0/API 23 or later with DreamService support. Verified on Android TV emulator-5570. Physical Fire TV and Google TV device behavior has not been verified. See [verification notes](../VERIFICATION.md).

## Install and upgrade

Run `python3 install.py --serial TV_IP:5555` to download the latest stable APK, verify its checksum, and install. There is no earlier public version to upgrade. Future updates must retain the package name and signing certificate. For manual installation, verify the APK with `rain-on-glass.apk.sha256` before installation.

## Changes

No breaking changes. This is the first public release and establishes version `1.0.0` and Android version code `1`.
